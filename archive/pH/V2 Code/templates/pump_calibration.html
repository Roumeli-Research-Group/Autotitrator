Pump Calibration

Instructions

  1. Ensure the pump is properly connected to the system.
  2. Enter the voltage range and the number of data points.
  3. Click "Start Calibration" to begin.
  4. A prompt will ask you to set the voltage and confirm measurements.
  5. After each measurement, input the output volume.
  6. Proceed to the next voltage until all measurements are complete.
  7. Review calibration results displayed on the graphs.
