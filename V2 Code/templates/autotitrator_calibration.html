Auto Titrator Calibration

Instructions

  1. Ensure that the titrator is set up correctly with the necessary reagents.
  2. Enter the experiment details in the input fields below.
  3. Click on the "Start Calibration" button to begin the calibration process.
  4. The titrator will perform automatic adjustments and calibrations.
  5. Once the calibration is complete, download the results as a CSV file.
